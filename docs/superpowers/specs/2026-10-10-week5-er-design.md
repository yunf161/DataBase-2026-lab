# 第五周 ER 模型设计约定

以当前 `sql/01_create_campus_store_database.sql` 为 v0.1 唯一结构依据。交付文件集中放在 `docs/week5-er/`：可编辑 `.drawio`、清晰 `.svg`、实体与键说明、逐条业务规则、问题清单、只读验证记录。原有 SQL 和正式数据库保持不变。

图使用统一的最小/最大基数表示法，关系两端分别标 `0..1`、`1..1`、`0..N` 或 `1..N`。实线表示 v0.1 中有外键的关系；虚线仅表示第六周拟议的会员方案。业务要求与数据库实际保障不一致时，在规则清单中分别说明，尤其是商品与库存、订单与明细。关联实体 `PurchaseItem` 和 `SaleItem` 分别拆解采购/销售订单与商品的 M:N 联系。

图与文字采用同一组实体名和关系名，图形由脚本生成 draw.io XML 与 SVG。验证只读核对系统目录中的表、外键和唯一键，以及样例采购、销售与库存，不改动业务数据。
