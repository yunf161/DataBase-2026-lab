# 第七周操作手册

启动及账号见[运行说明](README.md)。打开http://127.0.0.1:5070。

## 管理员

1. admin登录进入商品管理；按名称/SKU、状态查询。
2. 新增商品填写唯一SKU、名称、分类、售价和单位，条码/规格可选，保存后初始库存为零。
3. 编辑可改资料、价格和在售状态；有历史记录用停用。
4. 刚新增且无库存、无业务引用的商品可删除；删除可口可乐等历史商品会被拒绝并显示友好提示。
5. 库存查询显示数量、预警下限及状态；设置预警只改提醒阈值。
6. 销售订单按编号/状态查询，完成单可查看历史，草稿可维护明细。

## 店员

1. staff登录可查商品、库存、销售订单，没有管理员商品维护入口。
2. 销售订单点新建草稿，选择商品和数量加入明细。
3. 数量修改后点更新，移除不需要的商品，同一商品一单只占一行。
4. 选择支付方式、登记优惠和备注后保存。
5. 取消需二次确认，保留取消记录并停止修改。草稿显示明细合计，尚未结算、不扣库存。

## 顾客

1. customer登录只看到在售商品和我的订单，没有内部库存或商品维护页。
2. 商品页“加入草稿”建立本人草稿并加入1件商品，也可从我的订单新建空草稿。
3. 可以维护数量、添加/移除商品、保存支付方式与备注；不能指定单价和优惠。
4. 本周草稿等待店员受理，尚不构成已完成销售；可取消本人草稿。
5. customer2不能看customer的订单，直接请求接口也无法越权。

## 错误处理

输入格式、必填、数值范围同时由页面和后端检查。用户名/密码错误不区分账号是否存在。
重复SKU/条码、订单重复商品会明确拒绝，不留下半张订单。
账号停用立即使旧会话失效；页面/CSRF过期时刷新重试。
SQL服务不可用时只显示暂时无法连接数据服务，内部原因留在后端日志。
提示中的参考编号可供开发人员定位请求。

左下角按钮退出登录；手机布局仍保留退出按钮，表格在卡片内横向滚动。
