# 第八周 AI 使用记录

| 环节 | AI 辅助内容 | 人工核验及结果 |
| --- | --- | --- |
| 需求分析 | 对照《第7-9周任务讲解》梳理第八周角色页面、事务、集成测试及复现材料 | 以原文“应用开发（二）”为范围；沿用组内 SQL Server Express 选型 |
| SQL 与后端 | 协助编写受限视图/过程、路由、服务及参数化 DAO | 在随机 SQL Server 库运行真实集成测试，核对状态、库存与流水；库存不足和越权反例通过 |
| 页面 | 协助接入采购、盘点、销售结算入口和角色显示 | 使用真实 Edge 浏览器按管理员、店员、顾客操作；发现并修正登录初始化与导航的时序问题 |
| 文档 | 协助编写启动、增量部署、SSMS 查询和课堂演示步骤 | 核对命令、路径、测试结果与仓库实际文件，不把本地配置和测试库提交 |
| 代码审查 | 独立审查提出结算表单、登录失败、商品超过100件及直接 SQL 事务问题 | 先用失败用例复现，再修复并重跑真实数据库与浏览器验收 |

AI 生成的建议均以现有 SQL 脚本、Flask 代码和实际运行结果核实。自动化测试结果见[验证记录](verification.md)；AI 使用不替代组员对业务规则与实验结果的理解。
